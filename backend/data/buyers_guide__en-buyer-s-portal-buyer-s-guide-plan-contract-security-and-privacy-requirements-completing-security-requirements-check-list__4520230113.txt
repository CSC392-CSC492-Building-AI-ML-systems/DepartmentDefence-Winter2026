Completing the Security Requirements Check List
All requisitions and requisition amendments for contracts, standing offers or supply arrangements that include a security requirement must have an accompanying Security Requirements Check List ( SRCL ), the statement of work, and relevant security documents. These should include security clauses as provided by the Contract Security Program ( CSP ). Some clients may have specific agreements with the CSP with separate instructions. For each requisition involving security, the client must complete the relevant section on requisition form PWGSC-TPSGC 9200 (accessible only on the Government of Canada network) to confirm whether or not security provisions are included in the requirement.
Note: Some financial systems may not yet support the printing of this section. In such cases, the client's previous version of the requisition can be accepted provided it includes certification against the wording of the new security section. This certification can either be replicated in the "Special Instructions" section of the requisition or provided as a separate document.
Ensure that the completed security certification is included on each procurement file when the requisition lacks a properly completed security block. Clients can complete the SRCL either electronically via the online service or in hard copy using the form Security Requirements Check List ( SRCL ) . To use the online service register online or contact the Contract Security Program . The online service provided by the CSP provides a secure environment for completing the e- SRCL , reducing errors and providing the appropriate security clauses for the solicitation of offers within two working days as opposed to 15 working days for hard copies.
For further information, see Government Security or contact the CSP as the organization responsible for security screenings and clearances for Public Services and Procurement Canada ( PSPC ) procurements. The CSP will contact the client and the chief security officer for clarifications as needed. Security clauses should not be reused for similar solicitations without the CSP 's prior authorization due to constant updates and reviews.
