## Top-Level Files
- `main.py`: interactive chatbot CLI entrypoint.
- `collect_sources.py`: crawler/collector for policy pages into local corpus.
- `requirements.txt`: Python dependencies.
- `.env`: runtime configuration (API key + retrieval knobs).
- `readme.MD`: primary project overview.

## Core Package (`rag/`)
- `app_config.py`: all runtime defaults/environment parsing.
- `corpus.py`: document listing + chunking.
- `embedding_client.py`: Cohere client + embeddings helper.
- `pipeline.py`: document-to-embedding pipeline.
- `query_rewrite.py`: LLM-generated retrieval query expansion.
- `retrieval.py`: hybrid retrieval + Cohere rerank + selection logic.
- `prompting.py`: token-budget document packing (and legacy prompt builder).
- `rag_types.py`: shared dataclasses.

## Data (`data/`)
- Active corpus files (`*.txt`) used by `main.py` and evaluation scripts.
- `manifest.json`: metadata generated by `collect_sources.py`.

## Evaluation (`evaluation/`)
- `evaluation/eval_runner.py`: batch evaluation runner.
- `evaluation/eval_stack_runner.py`: structured evaluation runner with retrieval/answer/judge metrics.
- `evaluation/questions/*.txt`: prompt sets for different testing goals (one question per line; `#` comments ignored).
- `evaluation/cases/eval_cases.jsonl`: structured cases with expected evidence and deterministic checks.
- `evaluation/runs/*.json`: generated run artifacts (safe to delete and regenerate).
- `docs/EVAL_STACK.md`: workflow and metric definitions for the stack.

## Which File To Edit
- Change model/retrieval behavior:
  - `rag/retrieval.py`, `rag/prompting.py`, `rag/app_config.py`
- Change data ingestion/chunking:
  - `rag/corpus.py`, `collect_sources.py`
- Change CLI UX:
  - `main.py`
- Change benchmark automation:
  - `evaluation/eval_runner.py`, `evaluation/eval_stack_runner.py`
  - `evaluation/questions/*.txt`, `evaluation/cases/eval_cases.jsonl`
