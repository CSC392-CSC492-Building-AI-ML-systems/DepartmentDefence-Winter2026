## Security in standing offers and supply arrangements

When buyers and clients decide to use a standing offer or supply arrangement method of supply for procurements with a contract security requirement, the request should specify the required minimum level of security clearance. It should also indicate under what circumstances a higher security level would be required. Clear instructions must be provided on:

- how to identify which level of security applies in resulting contracts

- the client’s duty to confirm with the CSP that the offeror meets the security requirement, before issuing a contract or call-up

Note: When security capabilities like document safeguarding, IT (including cloud computing), production, and/or COMSEC are needed, verification of these specific security types from the CSP is crucial as they are contract-specific.

All resulting call-ups and contracts with security requirements must clearly state the security categorization, and the applicable SRCL must be attached to the call-up or contract documentation. A copy of all awarded call-ups and contracts with security requirements must be sent to the CSP via email.
