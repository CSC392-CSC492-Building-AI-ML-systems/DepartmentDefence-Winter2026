Changes to the complexity level If the buyer identifies that the procurement has been streamed incorrectly or if new factors arise that affect the complexity level, they are required to consult with the assigning manager to determine the appropriate complexity level. Incorrectly streamed procurements must be returned to the workload manager. The manager will reassign the file using the revised complexity code. The procurement must then follow the new process based on the new complexity level.
