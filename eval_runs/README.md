# eval_runs

This folder stores generated evaluation outputs from `eval_runner.py`.

- File type: JSON
- Typical contents: retrieval snapshots and optional chat answers
- Safe to delete: yes (runs are reproducible)

Examples:
- `baseline_with_chat.json`
- `hard_with_chat.json`
- `policy_conflicts_with_chat.json`

To regenerate, run commands from `docs/RUNBOOK.md`.
